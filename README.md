# Perceptron

Реализация алгоритма перцептрона на Python для решения задачи бинарной классификации.

## Возможности

- Обучение модели перцептрона.
- Классификация объектов на два класса.
- Генерация искусственных данных с помощью `make_blobs`.
- Работа с набором данных Iris.
- Построение границы решений модели.
- Визуализация ошибок при обучении.
- Оценка точности модели.
- Настройка параметров обучения через командную строку.
- Автоматическая проверка тестов и качества кода через GitHub Actions.

## Технологии

- Python 3.12
- NumPy
- Matplotlib
- Scikit-learn
- Pytest
- Mypy
- Ruff
- GitHub Actions

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/mfrtem/perceptron_lab.git
cd perceptron_lab
```

Установить зависимости:

```bash
uv sync
```

## Запуск

Для запуска программы с параметрами по умолчанию выполните команду:

```bash
uv run python -m perceptron_lab.main
```

Также можно задать параметры обучения самостоятельно:

```bash
uv run python -m perceptron_lab.main --samples 200 --lr 0.1 --epochs 50
```

Доступные параметры:

- `--samples` — количество генерируемых объектов.
- `--lr` — скорость обучения перцептрона.
- `--epochs` — максимальное количество эпох обучения.

Для просмотра всех доступных аргументов:

```bash
uv run python -m perceptron_lab.main --help
```

После запуска программа:

1. Генерирует искусственные данные.
2. Обучает перцептрон.
3. Выводит точность модели.
4. Строит границу решений.
5. Показывает график ошибок по эпохам.
6. Обучает модель на данных Iris и выводит точность.

Для Iris используются первые два класса и два признака. Точность рассчитывается на тех же данных, на которых обучалась модель.

## Тестирование

Для запуска тестов выполните команду:

```bash
uv run pytest
```

Для подробного отображения результатов:

```bash
uv run pytest -v
```

Тесты проверяют:

- Работу функции активации `activate()`.
- Предсказание классов методом `predict()`.
- Обучение модели методом `train()`.
- Расчёт точности методом `score()`.
- Генерацию искусственных данных.
- Загрузку и подготовку данных Iris.

## Mypy и Ruff

Для проверки типов используется Mypy в строгом режиме:

```bash
uv run mypy --strict src
```

Для проверки стиля кода используется Ruff:

```bash
uv run ruff check .
```

Для проверки форматирования:

```bash
uv run ruff format --check .
```

## GitHub Actions

В проекте настроен GitHub Actions для автоматической проверки кода при каждом `push` и `pull request` в ветку `main`.

Workflow выполняет:

- Установку Python и зависимостей.
- Запуск тестов Pytest.
- Проверку типов Mypy.
- Проверку стиля кода Ruff.
- Проверку форматирования Ruff.
