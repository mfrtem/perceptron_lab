# Perceptron

Реализация алгоритма перцептрона на Python для решения задачи бинарной классификации.

## Возможности

- Обучение модели перцептрона.
- Классификация объектов на два класса.
- Генерация искусственных данных с помощью `make_blobs`.
- Работа с набором данных Iris.
- Построение границы решений модели.
- Визуализация ошибок при обучении.
- Оценка точности модели.

## Технологии

- Python 3.12
- NumPy
- Matplotlib
- Scikit-learn
- Pytest
- Mypy
- Ruff

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/mfrtem/perceptron_lab.git
cd perceptron_lab
```

Установить зависимости:

```bash
uv sync
```

## Запуск

Для запуска программы выполните команду:

```bash
uv run python -m perceptron_lab.main
```

После запуска программа:

1. Генерирует искусственные данные.
2. Обучает перцептрон.
3. Выводит точность модели.
4. Строит границу решений.
5. Показывает график ошибок по эпохам.
6. Обучает модель на данных Iris и выводит точность.

## Тестирование

Для запуска тестов выполните команду:

```bash
uv run pytest
```

Для подробного отображения результатов:

```bash
uv run pytest -v
```

Тесты проверяют:

- Работу функции активации `activate()`.
- Предсказание классов методом `predict()`.
- Обучение модели методом `train()`.
- Расчёт точности методом `score()`.
- Генерацию искусственных данных.
- Загрузку и подготовку данных Iris.

## Mypy и Ruff

Для проверки типов используется Mypy в строгом режиме:

```bash
uv run mypy --strict src
```

Для проверки стиля кода используется Ruff:

```bash
uv run ruff check .
```

Для проверки форматирования:

```bash
uv run ruff format --check .
```
